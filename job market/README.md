# India Tech Job Market Analysis

## Project Overview
This project explores an India tech job market dataset for 2024–2026 using Python. It analyzes job titles, work modes, and average salaries to identify patterns in the available data.

## Objectives
- Explore and understand the dataset.
- Analyze the most common job titles.
- Compare work modes such as remote, hybrid, and on-site.
- Visualize average salaries across job titles.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- VS Code

## Visualizations
The project includes charts for:
- Top job titles
- Distribution of work modes
- Average salaries by job title

The charts are saved in the `data/charts/` folder.

## How to Run
1. Open the project folder in VS Code.
2. Activate your Python virtual environment.
3. Install the required libraries if needed:
   `pip install pandas matplotlib seaborn`
4. Run the analysis scripts:
   `python python/explore_data.py`
   `python python/job_title_chart.py`
   `python python/work_mode_chart.py`
   `python python/salary_analysis.py`

## Dataset
The project uses `india_job_market_2024_2026.csv`. Verify the dataset's original source and license before sharing it publicly.

## Disclaimer
This is an exploratory analysis of the supplied dataset. Its findings may not represent the entire Indian technology job market.
